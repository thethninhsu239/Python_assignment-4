# Python_assignment-4
# Student Management System

# Features
* add new student 
* edit students
* delete students
  
# Technologies Used
* HTML & CSS (Frontend)
* Python Django(Backend)
* SQLite (Database)

# How to run
* python--version
* python -m venv venv
* pip install django
* cd python_assignment-4
* python manage.py makemigrations
* python manage.py migrate
* python manage.py runserver
* http://127.0.0.1:8000/
